# 拼团公告

2026-10-12：按用户要求，在「拼团月卡管理」新增「拼团公告」页签，而非系统设置。

- 公告是一个支持换行的纯文本字段，最多 5000 个 Unicode 字符；预览和大厅均转义输出。
- 保存后替换大厅顶部原来的两段说明。空内容恢复现有多语言默认文案；恢复默认按钮只清空草稿，仍需保存。
- 仅影响大厅。购买规则、商品说明和实际计费规则不变。
- 使用现有 settings 表的 month_card_hall_announcement 键，无需迁移。
- 已登录用户 GET /api/v1/group-buy/announcement；管理员 GET/PUT /api/v1/admin/group-buy/announcement，沿用管理员权限、合规和审计中间件。
- 初次加载失败不能保存覆盖未知内容，可重试；保存失败保留草稿；页面刷新不丢弃未保存修改。
- 大厅公告独立加载，失败保留已知文案或默认内容，不影响浏览拼团。

UI 由 Kimi 以 --yolo 模式完成，保存及展示逻辑由主代理实现。
