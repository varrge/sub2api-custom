# Ultrafast 档位与独立倍率

渠道管理 → 编辑渠道 → OpenAI → 模型定价，或分组管理 → 编辑分组 → 模型定价，展开模型价格卡可设置 **Ultrafast 倍率**。

| 设置 | 计费方式 |
| --- | --- |
| 留空 / API `null` | 使用模型默认倍率；GPT-6.1 Sol、GPT-6 Astra 为 6 倍，其他模型保留原有默认行为 |
| `1` | Ultrafast 按标准档价格计费 |
| `3.5` 等正数 | 标准档各项 token 单价乘以该倍率 |

该配置独立于 Fast、Flex，覆盖模型默认值；分组价格卡优先于渠道价格卡。输入、输出、缓存写入、缓存读取均使用同一个 Ultrafast 倍率，之后仍按原有规则应用分组／用户等计费倍率。允许小于 1 的正数，不接受 0、负数或非有限值。

长上下文附加费与服务档位倍率分开计算。已有“0 到无限、各项区间倍率为 1”的渠道配置仍保持上下文平价，Ultrafast 倍率照常生效。GPT-6.1 Sol 订阅账号的模型长上下文豁免保持原有行为。

客户端请求需要携带 `"service_tier": "ultrafast"`，设置价格倍率不会切换请求档位。现有全局 Fast 策略也管理 Ultrafast 的允许／过滤／阻止；分组的“强制 OpenAI Fast”会把请求改为 `priority`，需要使用 Ultrafast 时应关闭该开关。“免费 OpenAI Fast”仅适用于 Fast/priority；Ultrafast 按标准价收费请将本倍率设为 `1`。

官方 OpenAI API Key 账号的 GPT-6.1 Sol 模型目录会声明 Ultrafast 能力；OAuth 和第三方账号以其上游模型目录为准。显式的上游能力声明优先于本地默认值。

部署时程序自动执行 `253_channel_ultrafast_multiplier.sql`，为渠道价格表新增可空字段。未填写的旧配置保持空值；部署后新的 GPT-6.1 Sol Ultrafast 调用默认从原有通用 2 倍修正为 6 倍。历史日志、已扣款项不会重算。回退旧程序可保留此新增列；旧程序不会应用此倍率，且用旧版编辑分组／渠道价格卡可能丢失新字段。
