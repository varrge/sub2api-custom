# 0.2.17-custom.6

基于 `v0.2.17-custom.5` 合并 `feat/monthcard-delete-repeat`。

- 管理后台拼团成员列表支持删除指定月卡。删除后权益失效、卡片从列表隐藏，但原招募名额保留，不退款，也不降低其他成员额度。
- 同一用户可以反复购买自己的团或其他团，每次成功购买生成独立月卡并占用一个名额；仍遵守满团、截止和取消限制。
- 保留订单、历史用量和支付回调幂等记录，覆盖删除与退款不同顺序的名额恢复处理。

升级执行迁移 `255_month_card_delete_repeat_join.sql`，移除同团同用户唯一约束，并增加删除记录和名额保留字段。代码与迁移需一起发布；产生重复购买或删除数据后，回退旧程序需先处理这些新数据，不能直接恢复原唯一约束。月卡价格及优惠配置未调整。

合并前后端全量 unit 测试（含本地真实 PostgreSQL 月卡测试）、前端 430 个文件 / 3,331 项测试、前端 ESLint、类型检查和生产构建通过，发布策略及 10 项发布辅助脚本测试通过。此前功能专项 race 检查、桌面与手机组件浏览器检查及独立代码审查也已完成。

本次发布按用户授权部署中国 `sub2api-multigroup-cn` 实例，只更新应用容器；部署前保存数据库、应用数据、Compose 和原应用回滚镜像。中国备份及验收证据保存于本机 Downloads 下的 `Sub2API-中国月卡删除重复参团-20261020T124139Z`。美国实例不在本次部署范围。
