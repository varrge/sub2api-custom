# 新月卡按购买独立存在，旧订阅保留原权益

现有同分组重复购买通过延长一条订阅的期限实现，额度上限属于分组，无法表达同一用户同时持有不同拼团档位、不同到期时间的同组月卡。依据本次需求及 Q1～Q12 的确认，新月卡每次购买形成独立权益，付款即起算 30 天，同团升档仅提高额度上限，保留已用量与时间边界；已有旧订阅保留原额度、期限和重置规则，与新月卡共同参与同分组消耗排序。这使后来购买的卡在排队消耗时也会消逝有效期，但保留了购买时刻起算和同组多卡的业务语义，并允许旧订阅逐步退出而不强制转换已有权益。

Q19 明确旧订阅经内嵌入口销售，销售入口的淘汰安排由用户自行负责；本功能不自动关闭旧销售、续费或兑换履约。具体数据表和迁移方式另行设计，混合扣费及账户欠费准入见 [ADR 0002](0002-card-and-balance-settlement.md)。
