## Seedance 适配

所有 `/api/v3`、`/v3`、`/v1` 和根路径下的视频任务接口统一接入自定义网关。新建任务只能选择 OpenAI 或解析到 OpenAI 的 Composite 分组，还须具备 Seedance 账号能力、分组媒体权限、用户使用资格和订阅/密钥配额。模型允许或禁用规则在多组选择前执行。

查询和删除根据 `seedance:` 命名空间找到原用户、密钥、分组和账号；调整当前分组顺序不会转移任务归属。删除采用既有的资源清理语义：解绑、额度耗尽或权益到期后，原持有人仍可清理任务，其他用户和密钥不能访问。原分组或账号不存在时不会切换其他账号。

创建时冻结 token 价格、倍率、计费时间、原始支付方式以及月卡/订阅权益。完成时按实际输出 token 结算，保留原卡和原周额度周期；不套用 Grok 的按秒价格。缺少有效 token 定价必须在创建前拒绝，明确配置的零价仍有效；缺失或不可用的历史快照不能进入零消费成功结算。

同一任务使用稳定结算 ID。月卡依靠持久事务幂等和失败恢复，不先占 Redis claim；余额和传统订阅在失败后释放 claim，允许重试。Seedance 完成记录进入强制用量队列，队列满时仍执行结算。

## 条件定时测试

「仅在模型受限时测试」默认关闭。开启后按 Cron 检查限流：健康时待命，受限时探测；搭配自动恢复可在成功后解除观察到且未被并发更新的限制。密钥模型禁用不是触发条件。Kimi 403 有明确重置时间时可触发，缺少重置快照而仅临时停调时保持原范围。

## 回滚要求

只替换应用镜像，不恢复数据库，不重建 PostgreSQL、Redis 或其他项目。若旧镜像不支持条件测试，回滚前仅停用已启用的 `only_when_model_limited=true` 计划并保存 ID 清单；不能把字段改为 `false`，否则旧版会持续普通定时探测。既有模型允许/禁用配置要求使用已支持该规则的回滚镜像。
