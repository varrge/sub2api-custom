# v0.2.25-custom.1

合并官方 v0.2.25，基于自定义版本 v0.2.22-custom.10，保留原生邀请码、首充返利及现有自定义业务。

## 更新

- 合入 GPT-6.2、上游分组同步、请求身份头模板、兼容转换和请求解析修复。
- 适配自定义渠道与分组定价，保留免 FAST、免 UF、缓存分档计费和独立倍率。GPT-6.2 的默认 UF 促销倍率按实际请求时刻计算，显式设置的倍率保持优先。
- 保留分组兜底账号、账号利润控制、多分组 Key、企业额度、月卡、支付退款、生图、Seedance、投票和教程功能。
- 保留管理员二次验证、管理接口通知、托管在线更新和凭据保护。
- 补齐多分组账单的分组信息，以及 Google 鉴权和 WebSocket 延迟选组后的上游身份头。
- 新增迁移 271，统一 UF 倍率的有限正数约束，不修改既有迁移和有效价格。
- 更新 OpenTelemetry 依赖，解决上一版本发布流程中的包级漏洞扫描阻塞。

## 发布方式

推送版本 tag 后，由 GitHub Actions 对固定提交执行 CI、安全扫描、构建和发布。构建产物通过后台原有在线更新流程安装。

## 已知限制

本次审查还记录了一个合并前已存在的问题：Responses 的 `input[].configuration_update` 中的 reasoning effort 尚未纳入分组的 effort 上限策略，现有策略处理顶层字段。这需要后续独立修复；本次合并没有增加或扩大该行为。
