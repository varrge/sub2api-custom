# 月卡冻结与取消招募（2026-09-12）

用户要求：指定团可以取消招募；月卡冻结期间暂停有效期与周额度周期，保留剩余时间和额度，在“我的订阅”随时自行解冻或再次冻结。按逐张卡操作实现，独购月卡同样适用，旧订阅保留原有行为。

## 业务规则

- 管理员可取消一个尚在招募的团，取消后大厅不再显示且拒绝后续参团，团号仍可查历史。不能重新开放；满团或已到期的团不再提供取消招募操作。重复取消幂等。
- 取消不撤销已售卡、回收已达档位额度或自动退款。取消前已付款但尚未成功发卡的订单会标记为待人工处理，不进入自动退款；管理员可在订单页按实际情况处理。
- 用户逐张冻结/解冻自己的有效月卡，不限次数和持续时间。已过期或撤销的卡不能恢复；退款卡不能借解冻复活。
- 冻结暂停该卡累计 30 天有效期和累计 7 天的周额度计时。解冻延续当前周期的已用量与剩余时间，最后不足七天的周期随卡到期结束。
- 冻结卡跳过新调用，保留消耗顺序与 API Key 分组配置资格；所有权益不可用时仍按现有规则拒绝新调用，余额仅补扣已开始调用的差额。
- 冻结前已准入的调用正常按准入时的卡和周周期结算；冻结本身不增减额度，但这些调用的实际费用仍应扣除。拼团招募与人数升档不暂停，冻结卡仍可获得升档加额。
- “我的订阅”使用浅蓝色冻结徽标、灰色日期区域、浅蓝色暂停提示与整行“解冻套餐”按钮，显示保留的剩余时间及额度。
- 大厅最多返回 200 个尚在招募的团，按开团时间、ID 从新到旧。页面按分组过滤此列表，满团不展示；当前没有分页。超出列表上限的团可通过团号查询。本次不调整上限。

## 时钟与发布

付款起止锚点与账本周键保持不变，累计冻结时长独立存储。准入快照携带当时的累计冻结时长；省略新字段的旧快照按零处理。列表中的到期与重置时间是按冻结时长顺延后的预计墙钟时间，冻结期间剩余秒数固定。

迁移 240 只增加冻结字段并扩展状态约束，原有卡默认未冻结、累计冻结时长零。产生冻结记录后不能直接降级到不了解冻结时钟的旧应用，需保留时钟兼容的修复版本；不得自动恢复数据库覆盖新增交易。先在中国独立演练环境验收，再更新中国 staging 应用，日本生产仍需单独确认。

## 验收

真实 PostgreSQL 测试覆盖冻结跨原始到期、多次冻结解冻、周边界、卡到期、保留消费顺序、冻结时在途跨卡与余额补扣、退款防复活、冻结时升档、持久化补扣重试与幂等、取消和参团并发。前端验证单卡状态操作、失败重试、管理员指定团确认、取消后禁用参团和冻结显示。
