# 一次调用允许由多张卡和账户余额共同承担费用

调用的实际费用通常在完成后才确定，而同组多卡需要独立遵守各自的周额度和总额度。根据 Q13、Q16～Q18 的确认，一次调用先按开始时的卡、排序和周周期跨卡分摊，再将卡额度无法覆盖的差额按正常调用费用扣账户余额；卡扣费与余额补扣的合计必须等于实际调用费用，允许补扣形成负余额，欠费阻止后续调用直至结清。余额仅承担已开始调用的差额，不授予没有可用订阅权益的用户在该订阅分组发起新调用的资格。

并发结算不能重复消耗同一份卡额度，跨周或跨到期的在途调用仍归属开始时的卡和周期，因此历史周期扣费记录必须能够在新周期开始后继续结算。此选择允许无法事先精确确定费用的调用按实际费用完成结算，但账户欠费可能因多个在途请求而扩大；它不承诺整次调用费用被卡额度封顶。
