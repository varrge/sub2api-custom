# 手动清零本周用量同步扣减累计用量

管理员在订阅月卡管理中选择「清零本周已用」后，本周已用归零，累计已用同时减去清零前的本周已用，最低为 0。例如总额度 400、累计已用 55、本周已用 30，保存后为本周 0、累计 25、总剩余 375。单张与批量重置采用相同规则。

选择「清零累计已用」仍将累计直接归零；同时选择两项时两个计数都归零。弹窗在保存前展示预计的本周与累计结果；实际操作使用事务加锁后读取的数值。先前单独清零累计可能使累计小于本周，扣减结果不得为负数。

只改变管理员手动操作。每七天自动换周继续保留累计用量。额度上限、有效期、周周期、已扣账户余额及消费历史不变；无需新增数据库迁移。重置审计继续保留重置前的精确累计和本周值及操作选项。

重置清除的是保存时已结算的用量。尚未结算的请求继续在原来的周周期和重置代次结算：仅重置周用量时，后续结算仍增加累计，不会重新填入新一轮本周计数；显式清零累计时沿用原有累计历史代次隔离规则。

验证覆盖真实 PostgreSQL 的 55→25、8 位小数精度、重复重置、不存在本周记录、累计小于本周、冻结与批量操作、审计回滚、迟到请求和幂等结算。前端验证单张/批量预览及已有保存流程。
