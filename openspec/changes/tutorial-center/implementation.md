# 教程中心实现与验收

日期：2026-11-11。工作分支：`codex/tutorial-center`。

## 范围与布局

采用用户从 Gemini 设计方案中选定的 C 工作台：左侧选择平台、密钥、分组、客户端、运行环境、模型和线路，右侧生成配置并展示教程与 FAQ。原始 A/B/C 方案保存在 `codex/tutorial-center-prototype` 的 `5de87acb9`，正式实现不包含原型路由或模拟数据。

- 用户入口：`/tutorial`；管理员管理页：`/admin/tutorial`。
- 管理员可维护教程、FAQ 和线路，支持 Markdown、图片、草稿/发布、平台/客户端筛选及排序。
- 复用原“使用密钥”配置生成器，保留现有客户端配置格式；密钥弹窗增加教程入口。
- 不包含线路测速。生成配置不会请求上游推理接口。

## 启用与数据

数据库迁移 `266_tutorial_center.sql` 创建单行 JSONB 内容表及 `tutorial_enabled=false` 默认设置。更新程序执行迁移后，在“系统设置 → 功能开关 → 教程中心入口”开启并保存。管理员可先编辑内容，再开放入口。

关闭开关时，顶部/侧栏隐藏入口，用户页面禁止访问，用户内容 API 返回 403；管理员仍能管理内容。新设置保留现有部分更新行为，未传此字段时不覆盖它。

内容上限：50 篇教程/FAQ、20 条线路，单篇 Markdown 512 KiB、总内容 6 MiB、标题 120 字符；上传图片限制 300 KiB。保存通过 revision 做原子并发检查，冲突返回 409，保留编辑器内未保存内容。

## 权限与配置语义

模型选择取分组模型目录、密钥绑定分组、模型允许/拒绝策略及按模型分组路由的交集；失效、过期或配额耗尽的密钥不能生成可用配置。编程客户端过滤专用生图、生视频、语音、嵌入及重排模型。Antigravity 根据客户端协议过滤混合模型。

分组选择仅决定配置示例，不更改密钥实际路由优先级。接入地址来自站点 API 地址或管理员发布的线路。

默认使用 `YOUR_API_KEY`；用户显式勾选后才把所选密钥写入当前配置。分享链接只包含公开选择项，不包含密钥或密钥 ID。所选密钥保留在页面内存中，不写入持久化存储；异步请求有过期响应保护。分享配置在密钥慢速加载时仍能恢复指定模型。

用户内容 API 在服务端剔除草稿正文和草稿线路。Markdown 使用 DOMPurify 白名单，禁止脚本、iframe 和内联 SVG；链接限定 HTTP(S)/页内锚点，外链附带安全属性。管理员线路地址、平台及客户端字段均做服务端校验。

## 构建兼容调整

锁定依赖 `vue-i18n@11.4.16`，本项目语言文件使用消息字符串。Vite 改用含消息编译器的完整构建，解决运行时直接显示翻译键的问题；该版本默认使用 JIT AST 模式。未改动依赖清单或锁文件。

- 前端类型检查、针对变更文件的 ESLint 和生产构建通过。
- 密钥配置弹窗、教程权限/分享/Markdown、教程异步逻辑、功能路由、原模型权限及国际化相关测试通过。
