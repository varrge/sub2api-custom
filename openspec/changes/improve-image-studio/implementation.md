# 生图工作台改造记录

日期：2026-11-07。参考基线：影策 `ddcat-ai/open-ai-canvas` 的 `cd2512eb9ba0aa7fa97ac7a72cb0d97c44c36828`（v1.8.2）。本项目基线：`f24cc29c4a20aa1ebde69933e0b32e72bb8e2017`。

## 已落实

- 多图请求逐次保存成功结果；后续失败时保留已有图片和真实完成数量。
- 每次请求保存规范化参数、原密钥 ID、参考文件与结果关联，排除密钥秘密。可以复用参数、浏览同批缩略图、将结果作为参考图。
- 参考图支持预览、前后调序、删除、清空；超量输入明确提示。结果转参考图限制下载体积、类型、协议和时长，不转发账户凭据。
- 历史记录支持提示词/模型/会话搜索、显式重命名和删除。失效的历史密钥不会自动替换成其他计费分组；用户明确切换密钥时才重选模型。
- 新增只读能力查询 `GET /v1/images/capabilities`（兼容 `/images/capabilities`）。按原密钥分组判断，仅原生 OpenAI/Grok 且配置完整时启用现有异步接口；Composite 不跟随目标模型误启用。
- 异步任务 ID 落盘后轮询；刷新只查询原任务，并使用原密钥，包括可查询已受理任务的额度耗尽密钥。查询失败保留任务；结果不确定时不自动补发，另一次生成需要明确确认。
- 分辨率、比例、画质使用共用能力解析。画质与分辨率保持独立。原有视频入口、路由开关和草稿保留。
