# 我的拼团：月卡 A 版

用户从三版原型中选择 A（典藏主卡）。原型保留于 `prototype/monthcard-2-5d` 分支；本实现基于 `custom/0.2.18`，在 `feat/monthcard-wallet` 分支独立接入真实数据和操作。

页面最初采用 Gemini 生成的主卡左、权益右、卡包下方布局。用户进一步选择放大卡面，将可用额度、周/总进度、剩余天数和重置时间全部纳入同一张权益卡。当前布局为居中最大960px的大卡面，操作按钮在卡面下方，卡包继续位于其后。Gemini通过已配置的兼容接口输出卡面模板和样式，主代理接入真实字段、状态管理、排序、冻结、价格、卡面和回归验证。

## 可见性与扣费顺序

- 卡包仅展示未过期的有效月卡，以及尚有剩余时长的冻结月卡。到期后从卡包自动移除；不删除后台月卡、支付订单或历史扣费记录。
- 冻结卡保留位置，扣费自动跳过；有效期及周周期按既有冻结规则处理。冻结卡不显示可立即消费的额度。
- 每个分组单独拖动排序，松手后调用既有全量排序接口保存；不允许跨分组移动。同组官方订阅会一同显示并参与排序。
- 键盘聚焦拖动柄时，可用方向键调整。触屏按住拖动柄操作，页面其他区域仍可正常滚动。
- 保存时禁用重复提交，失败回退并提示；接口要求完整有效权益集合，隐藏的服务端引用保留原位置。拖动期间到期或权益变动时重新校验，不伪报成功。
- 选中卡与排序相互独立；切换账号时清空状态并忽略旧账号请求的迟到响应。

## 卡号、团号和价格

卡面上的 `C…` 是独立月卡的卡号，不是团号。团号 `T…` 在详情中单独展示，可进入对应拼团；独购卡显示“单独购买”。

卡包底部显示购卡金额，悬停、点击或键盘聚焦可查看原标价和购卡金额。价格单位为人民币，购卡金额不含支付手续费。

后端仅向持卡本人 `ListCards(userID)` 附加：

```text
original_price_cny: 购买订单快照中的原标价，可缺省
purchase_price_cny: 支付订单 amount 中的购卡金额，可缺省
```

不使用后来编辑的商品价格推断历史金额。公共团成员列表不返回其他用户的购卡价格。缺失的历史快照显示“暂无记录”。

## 统一卡面装扮接入点

所有档位使用同一个 `MonthCardFace` 模板、同一张默认卡面。产品名称、持有人、卡号、有效期是独立文字层，不烘焙进图片。冻结标识也不要求另一套图片。

页面 `MyGroupBuyView` 接受一个可选的 `appearance` 属性，并透传给卡面：

```ts
interface MonthCardAppearance {
  id: string
  name: string
  imageUrl?: string
  textColor?: string
}
```

将来领取/装备系统只需提供已授权的装扮描述。例如：

```ts
const appearance = {
  id: 'sakura-gift',
  name: '樱花礼遇',
  imageUrl: '/month-card-appearances/sakura.webp',
  textColor: '#fff6e8',
}
```

一张横向背景图适用于全部档位，建议1620×1000；图片以 `object-fit: cover` 覆盖底层，产品文字、额度和账号字段自动叠加。桌面卡面约1.7:1，手机端按内容增高，同一背景图会自动裁切，重要画面应尽量居中。上传装扮图上方附加暗色遮罩帮助信息阅读。图片只允许站内路径或HTTPS地址，加载失败回退到默认卡面，文字颜色限定六位十六进制值。

本次不引入装扮库存、赠送、兑换、上传或装备数据库；只预留组件接入点。日后授权和拥有关系应由服务器验证，不能仅信任前端提供的装扮ID。

## 鼠标动效与预览

卡面以自身中心为锚点，鼠标角落最大约±4°旋转，光泽随指针移动；离开、取消、切换卡时回正。触屏及减少动态效果模式关闭旋转。操作按钮位于卡面外。
