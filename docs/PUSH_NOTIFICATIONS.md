# 推送通知

入口：**系统设置 → 推送通知**。每个渠道可以单独配置接收地址、触发事件、标题、Markdown 正文和标签，最多 10 个渠道。

## 配置

- **Server 酱**：填写 SendKey，支持 `SCT…`（Turbo）和 `sctp…`（Server 酱³）。通道编号可选，多个编号用 `|` 分隔。
- **自定义 Webhook**：填写公网 HTTP/HTTPS 地址，选择 JSON 或表单格式。链接中的令牌会按凭据保存；禁止内网地址和重定向。
- 保存后密钥／链接不再回显，留空表示保留。不同渠道可以接收不同的事件。
- 标题、正文、标签支持下表变量。正文支持 Markdown；标签以 `|` 分隔。Server 酱³ 使用原生标签，Turbo 将标签附在正文中。
- 先生成预览，再保存。**真实测试发送**会向已保存的渠道发送测试通知，总开关关闭时也允许测试；每个渠道 30 秒内最多一次。
- 打开总开关和渠道开关后，只接收启用后发生的新事件，不补发历史订单。

## 事件

| 事件 | 触发条件 |
| --- | --- |
| 充值成功 | 在线余额充值订单完成到账 |
| 订阅购买成功 | 订阅订单完成履约 |
| 月卡购买成功 | 月卡已发卡且订单完成；未发卡的自动退款订单不通知 |
| 拼团已满 | 拼团首次达到满团；同一团不会因状态来回变化而重复通知 |
| 运行告警 | 已配置的运行监控规则生成告警记录 |
| 共享额度不足 | 共享活动生效期间，可用原价额度（总额减已用、预占）低于或等于渠道阈值；每个活动配置版本提醒一次 |

这里的额度不足指全站共享额度；不逐次检查每个用户余额。管理员手工改余额、兑换码充值不属于在线充值事件。

## 模板变量

| 变量 | 含义 |
| --- | --- |
| `{{site_name}}` | 站点名称 |
| `{{event_name}}` | 事件中文名称 |
| `{{event_id}}` | 事件编号 |
| `{{occurred_at}}` | 北京时间 |
| `{{summary}}` | 事件摘要 |
| `{{details}}` | 预置的 Markdown 事件详情 |
| `{{user_id}}` / `{{order_id}}` / `{{amount}}` | 订单用户、订单编号、实际支付金额 |
| `{{currency}}` | 支付币种，例如 CNY、USD |
| `{{product_name}}` / `{{team_code}}` | 月卡名称、团号 |
| `{{remaining_quota}}` | 共享剩余额度（USD） |

当前事件没有的字段会替换为空，建议用 `{{event_name}}` 作为标题，用 `{{details}}` 展示对应事件的具体信息。Server 酱标题最多保留 32 个字符。

```markdown
## {{event_name}}

{{summary}}

{{details}}

---
站点：{{site_name}}
时间：{{occurred_at}}
```

## 自定义 Webhook 请求

使用 HTTP POST；JSON 和表单字段一致：

```json
{
  "title": "拼团已满 · 示例站点",
  "desp": "## 拼团已满\n\n- **团号**：T-demo",
  "tags": "月卡|运营",
  "event": "team.full",
  "event_id": "42",
  "occurred_at": "2026-11-04T08:00:00Z"
}
```

返回 HTTP 2xx 视为成功；Server 酱还会检查响应中的成功状态码。自定义渠道是通用接口，第三方服务若要求不同的 JSON 结构，需要使用自己的转发地址适配。

## 投递记录与重试

通知在独立队列中发送，约每 15 秒处理一次，不等待第三方 HTTP 返回来完成订单。发送失败最多尝试 3 次，前两次失败后分别等待至少 30、60 秒；服务重启后继续处理待发送记录。后台显示最近 50 条结果、次数和失败原因。

每个渠道的同一业务事件只入队一次。网络超时可能发生“接收方已收到但发送方未收到响应”，因此重试仍可能产生重复通知；自定义接收方可按稳定的 `X-Notification-ID` 请求头去重。

关闭渠道、取消事件、修改地址或关闭总开关会取消相应待发送通知及失败重试。已经发出的请求可能完成，无法撤回。模板变更影响之后入队的通知。

## 验证

```sh
cd backend
PUSH_NOTIFICATION_TEST_DSN='postgres://user:password@localhost/test_db?sslmode=disable' go test -race ./internal/pushnotify
```
