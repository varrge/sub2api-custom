# 0.2.17-custom.7

基于 `v0.2.17-custom.6` 移植企业模式、特权规则与可选欢迎动效。保留此基线的月卡删除/重复购买、冻结与周配额、模型访问控制、FAST/Ultrafast 计费和展示。

- 管理员可创建或转换企业用户。企业身份由服务端控制，固定企业界面，不参与拼团月卡、订阅、普通充值优惠、返利和活动榜；充值与工单入口遵循站点开关。
- 每个用户可配置独立的分组企业倍率；未设置时按原有倍率规则回退。企业余额充值倍率独立配置，默认 1。
- 转换前预览有效月卡剩余总额度，按管理员确认的倍率一次性折算余额；保留并发准入、幂等、退款冲回及审计。适配新版冻结月卡时钟和固定费用预占，未结算任务会阻止转换。
- 企业模型广场默认只看已配置的企业报价，可取消后查看普通报价；使用记录提供月度 ZIP 对账导出。
- 系统设置新增“特权设置”：普通用户可按累计 API 消费、累计充值入账、注册天数或管理员指定用户匹配展示头衔。规则按列表顺序取首条，可关闭、排序和预览，不改变身份、余额或权限。
- 企业与每条普通规则可分别选择 A 暖金胶囊、B 侧滑卡片、C 光环徽章、D 流光横幅。旧设置保留 A，旧客户端保存不会清空新设置；支持手机、深浅主题、手动关闭和减少动态效果。

升级新增迁移 `256_enterprise_accounts.sql`，不修改历史迁移。创建企业身份或发生月卡折算后，不可直接回退到不识别企业限制的旧程序；需先核对身份、折算余额、月卡状态与退款记录，制定数据兼容方案。

活动榜沿用 60 秒共享快照刷新，身份变更后旧榜可能短暂保留旧排名，权限限制立即生效。展示头衔按现有保留使用记录及已入账订单计算，不是永久权益授予。

验证与合并信息见 [port-0217.md](../openspec/changes/add-enterprise-mode/port-0217.md)。源码发布不代表生产部署；旧中国企业验收实例仍使用单独的 0.2.0 候选镜像，本次未更新该实例或其他服务器。
