# v0.2.20-custom.4

新增教程中心，采用左侧配置、右侧代码的工作台布局。用户可按平台、密钥、分组、客户端、运行环境、模型与线路生成配置，并复制、下载或分享不含密钥的配置选择。

管理员可维护教程、图片、FAQ 和线路，设置草稿/发布、排序及适用平台/客户端。系统设置的功能开关新增“教程中心入口”，默认关闭；开启后在顶部及侧栏显示“使用教程”。

配置生成沿用“使用密钥”弹窗的现有客户端格式，结合密钥和分组权限过滤模型，并排除专用媒体模型。新增迁移 `266_tutorial_center.sql`，保存内容时检测并发编辑冲突，用户接口不返回草稿。

修复字符串语言包在运行时显示翻译键的问题，并将教程权限、配置生成和 PostgreSQL 并发测试接入发布 CI。

升级后先在“教程管理”配置内容，再到“系统设置 → 功能开关”开启入口。此版本未加入线路测速。
