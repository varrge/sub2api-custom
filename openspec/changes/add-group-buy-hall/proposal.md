# 拼团大厅与独立月卡

现有同分组订阅重复购买会延长期限，额度上限属于分组，无法表达同一用户同时持有多张不同额度、不同到期时间的同组月卡。本方案新增按购买独立存在的月卡、按已付款人数加额的拼团，以及同组权益排序、跨卡分摊和余额补扣。

用户通过现有购买页中的“拼团”页签单购或开团，通过拼团大厅加入正在招募的团，在现有“我的订阅”查看和调整月卡顺序。每张卡付款即起算 30 天，按付款时刻每七天重置周额度，额度不足的已开始调用可补扣余额；没有可用卡时不能凭余额继续调用，欠费时暂停账户新调用。

19 组需求访谈对应功能已实现，新增迁移及本地全量测试、真实 PostgreSQL 并发测试、构建、页面检查和独立审查已完成。尚未提交、推送或部署。旧订阅权益保持兼容，其内嵌销售入口的淘汰安排由用户自行处理。
