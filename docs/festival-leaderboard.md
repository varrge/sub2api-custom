# 活动消费榜（系统功能）

顶部入口顺序：主题切换 → 双节消费榜（奖杯）→ 余额。点击在奖杯下方展开靠右的非模态下拉浮层，展示前 20 名及当前用户自己的排名；榜单仅登录后可见。

## 统计口径

- 活动时间：北京时间 2026-09-25 00:00（含）至 2026-10-08 00:00（不含）。这是首次使用的默认配置；管理员可以在系统设置中修改，普通用户的查询参数无法修改统计范围。
- 按 `usage_logs.created_at` 归属活动，累加 `actual_cost > 0` 的调用记录。包含全分组、所有模型和媒体、余额、订阅及拼团月卡，保留每次调用落账时的个人/优惠倍率；不使用当前分组倍率重新计算。
- 充值和套餐购买金额不属于调用消耗。月卡分摊、余额补扣不单独重复相加；依赖已有 `(request_id, api_key_id)` 唯一约束避免请求重试重复记账。
- 存在于 `month_card_billing_pending` 的待结算请求暂不计入，恢复成功后按原调用记录时间计入。统计基于用量记录，不能替代支付流水或财务核账。
- 排除管理员与已删除账号。普通测试账号不会根据邮箱或昵称自动排除；本次未加入测试账号名单管理，发奖前需核验资格。
- 金额以 PostgreSQL NUMERIC 原精度排序；同额按最后一笔正计费时间较早者优先，再按内部用户 ID 排序。前端显示最多四位小数，完整额度可通过金额提示查看。
- 展示的是**计费额度，不是人民币实付金额**。前三名奖励仅展示“另行公布”，未写入未经确认的奖励金额。

## 接口和缓存

`GET /api/v1/activities/leaderboard`（兼容旧路径 `/api/v1/activities/double-festival/leaderboard`）使用现有 JWT 认证、用户后台模式守卫和面板重查询限流。只返回匿名编号、名次和额度，不返回邮箱、用户名或其他用户 ID；编号由 JWT 密钥对活动 ID 和用户 ID 做 HMAC 后截取 48 位生成。更换 JWT 密钥将改变匿名编号。

每个进程保留一份活动快照，60 秒有效，并合并并发刷新请求；查询有 15 秒超时。Top 20 与本人排名来自同一快照，返回时复制个性化字段，HTTP 使用 `private, no-store`。未开始时不查询用量表；活动结束后继续定期重算以接纳延迟结算，页面注明奖励以核验为准。

轻量配置接口在页面可见时每分钟刷新，关闭功能后隐藏入口；用量聚合在浮层打开后才请求，打开期间每分钟刷新，后台标签页暂停定时请求；关闭/卸载会取消请求并清理定时器。刷新失败保留上次数据并提示，首次失败提供重试。日期始终按北京时间展示，中英文、明暗主题均支持。

## 系统设置

管理员在 **系统设置 → 消费榜** 独立保存以下配置：

- 开关：关闭后入口隐藏，数据接口也返回空榜，不扫描用量表。
- 标题（1–80 字）、副标题（最多 160 字）、奖励说明（最多 1000 字）。文案按纯文本展示。
- 开始/结束时间：管理界面统一北京时间，接口必须提供含时区的 RFC3339 时间，开始时间含、结束时间不含。结束必须晚于开始，单次活动最长 366 天。
- 可选演示截止时间：只能在活动开始前启用，截止时间不得晚于开始；留空关闭预览。

`GET/PUT /api/v1/admin/settings/activity-leaderboard` 使用现有管理员认证和审计；PUT 完整保存配置，非法/不完整提交不覆盖旧配置。配置以 `settings.activity_leaderboard` 的单条 JSON 持久保存，无数据库迁移。普通系统设置保存不会覆盖这条配置。

`GET /api/v1/activities/leaderboard/config` 是登录后的轻量配置接口，不查询用量榜单。后端每次读取配置，保存后后续请求立即使用新配置；其他浏览器最多在下一次可见页面配置刷新时同步。配置读取错误不会回退到旧榜或擅自启用默认活动。

统计时间变化会产生新的活动标识、匿名编号及缓存；只修改标题/文案不改变匿名编号。配置内容和活动状态均参与缓存隔离，配置改变后不会复用另一时间段的榜单。单进程仍只保留一个用量快照。当前功能管理一场活动，不保存历史活动档案；如需保留历史榜单，应在调整日期前另行导出。

## 演示预览

演示启用时返回 8 条独立示例，任何用户看到的“我的排名”示例均为第 4 名；页面明确说明名次和额度均为模拟，并显示到期时间。不会新增用户、修改余额或写入调用记录，也不进入真实统计缓存。演示到期或正式活动开始后自动停止。

此前临时环境变量 `ACTIVITY_LEADERBOARD_DEMO_UNTIL` 已移除，演示改由上述系统设置管理。此次中国测试部署延续已有的 `2026-09-23T19:23:36+08:00` 截止时间，不延长演示。提前关闭只需清空系统设置中的演示截止时间并保存。
