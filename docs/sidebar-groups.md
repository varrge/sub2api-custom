# 侧栏分组与菜单图标

系统设置的「侧栏分组」可管理用户侧栏和管理侧栏。新建分组后填写名称，选择显示范围，再添加已有页面。页面与分组都可以上下调整顺序。

- 可添加内置页面和已保存的自定义菜单。同一显示范围内，一个页面只能属于一个分组。
- 新分组显示在未分组页面上方；未分组页面保留原有顺序。
- 管理员原有的渠道管理、订单管理等目录可整体加入分组，子页面保持原样。
- 从分组移除页面或删除分组，会恢复原来的菜单入口，不会删除页面。
- 修改显示范围会清空该组所选页面，需要重新选择。
- 分组不改变页面权限。功能关闭、简单模式或账户权限隐藏的页面，仍然隐藏；空组不显示。
- 用户分组也适用于管理员的「我的账户」，但仍遵守该区域原有的显示规则。
- 没有分组配置时，使用原侧栏。已有自定义菜单无需修改。

「侧栏分组」独立保存，不会提交其他系统设置。最多 32 个分组，名称 1–64 字，每组最多 64 个页面，总计最多 256 个页面。

## SVG 图标

系统设置的自定义菜单支持点选抽奖、邀请码、BOSS 三类预设，也可以继续上传 SVG。选中后保存该菜单的系统设置即可生效。现有图标不会自动替换。

共九个图标和预览页位于 [`frontend/public/menu-icons`](../frontend/public/menu-icons/README.md)，网站访问路径为 `/menu-icons/index.html`。图标来自 Lucide，保留来源版本与原始许可证，描边颜色跟随主题。

## 数据接口

管理员独立接口：`GET /api/v1/admin/settings/sidebar-groups`、`PUT /api/v1/admin/settings/sidebar-groups`。

```json
{
  "groups": [
    {
      "id": "tools",
      "label": "常用工具",
      "visibility": "user",
      "items": ["/keys", "/usage"]
    }
  ]
}
```

配置保存在现有 settings 表的 `sidebar_groups` 键，不需要数据库迁移。公开设置与页面初始化数据只返回用户分组。前端先完成权限、功能开关过滤，再按配置重排已有菜单，配置不能创建路由或授予访问权限。独立保存会使页面初始化配置缓存失效。

## 同批界面调整

- 密钥弹窗在桌面端加宽到 896px；编辑时顶部提供「基础设置 / 模型限制」页签，切换保留未保存的输入。保存发现错误时会切到对应页签。手机端保持单列布局。
- 冻结提示简化为「冻结不计时、不重置额度，解冻后接着用」。月卡规则保留累计 30 天、每 7 天重置周额度、冻结暂停有效期和周期等实际含义，仅修改文案。
