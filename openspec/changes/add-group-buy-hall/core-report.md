# 月卡核心存储实现报告

更新时间：2026-09-10。核心存储已实现，代码未提交或推送。

## 文件与行为

- `backend/migrations/238_month_card_core.sql`：独立商品、团、卡和混合权益排序表；保留旧订阅唯一约束。数据库约束保证订单一卡、用户每团一次（包括已退款会员）、卡号/团号唯一及额度上限。
- `backend/internal/monthcard/store.go`：共享模型、SQL Store、用户/分组绑定资格验证。
- `products.go`：商品查询、上下架及配置保存；仅允许有效订阅分组；金额使用 decimal，人民币最多两位小数、额度最多八位。
- `teams.go`：大厅、团号查询与购买准备；开团规则快照；下架或修改商品不影响已有团的参团规则；默认招募 48 小时。
- `fulfillment.go`：支付订单状态校验、付款时间起算、独购/开团/参团履约、幂等重试、团人数竞争、全团升额、退款撤卡。退款后保留历史升额，不重开已满/结束的团。
- `cards.go`：我的卡、管理员卡、团成员卡、订单对应卡及退款重试协调；周周期从付款时刻滚动，第五周截至第 30 天；当前周用量使用结算所有者的历史周期表。
- `ordering.go`：同用户同组新旧权益全量排序校验；初始按到期/开始时间/ID，之后新卡追加；暂时额度耗尽的权益保留排序。
- `core_test.go`、`core_postgres_test.go`：边界验证及真实 PostgreSQL 事务和并发测试。

## 并发与集成约定

核心的最终锁序为 `user -> payment_order -> team -> cards 按 ID 升序`。结算先锁用户并按 ID 预锁所有候选卡，再按用户消费顺序分摊；升档不获取其他团员的用户锁。参团先独立锁团，再以新 SQL 语句读取最新人数/会员，避免锁等待之前的语句快照导致超卖。

履约仅接受 `PAID/RECHARGING/COMPLETED` 的 `month_card` 订单，已存 `paid_at` 优先于调用参数。订单唯一约束和用户行锁让重复回调返回同一张卡。`PreparePurchase` 返回服务端购买快照；主代理将其持久化到付款订单并传入履约。

`RevokeOrder` 必须看到已提交的 `REFUNDED`；对没有卡的失败参团退款直接幂等成功。`ReconcileRefunds` 分批重试待撤卡的已退款订单。在重试间隙，团人数与卡展示也会排除已退款订单；结算准入/扣费同样由结算所有者检查订单状态。商品/分组在付款后变为不可购买时，语义资格错误返回 `ErrCannotJoin` 供原路退款；数据库故障保留原错误，避免把临时故障误判为应退款。

附加接口：`GetOrders(ctx,userID)`、`TeamCards(ctx,teamID)`、`GetCardByOrder(ctx,orderID)`、`ReconcileRefunds(ctx)`。仅管理员可调用 `ListCards(ctx,0)`，最多返回最近 100 张；用户 HTTP 层必须传入已认证用户 ID。

## 验证

PostgreSQL 16.14，本机临时新建集群；每项测试使用独立随机 schema，装载实际 238/239 迁移，未访问应用数据库。

```sh
MONTHCARD_TEST_DSN='postgres://.../postgres?sslmode=disable' \
GOTOOLCHAIN=go1.27.0 go test -race ./internal/monthcard -run TestCore -count=1
```

通过（2.454 秒）。覆盖：

- 十二个同时到达的付款回调只创建一团一卡；同一用户两个订单并发参团仅一个成功。
- 十三个用户竞争最后一个名额仅一人成功；关闭招募拒绝到账参团；满团退款不重开。
- 分组公开限制、专属授权及分组类型校验；修改商品价格、分组、名称、人数和上下架后，已有团仍按原快照售卡。
- 达档升额保留已用额度、周窗口和过期时间；退款不回收其他人的额度；退款会员不贡献后续升档且无法重入。
- 同组多卡独立持有；新旧权益排序全量原子校验；重复、遗漏和他人权益被拒绝；新卡追加。
- 付款时刻作为起点、第 29 天进入第五周、到期后的周期历史展示；旧订阅唯一索引保持有效。
- 未付款订单不能发卡；无法参团且没有卡的退款撤销幂等成功；金额、档位、人数、招募时长配置校验。

## 验证边界

这些测试验证实际核心迁移和事务 SQL，使用最小既有表夹具；不代替主代理的全库迁移、HTTP/支付渠道、鉴权与结算端到端检查。外部支付退款和退款后恢复重试的调度由主代理负责。此报告不代表已发布或已在生产环境验证。
